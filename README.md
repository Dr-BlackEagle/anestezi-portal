# Asistan Portal

Anesteziyoloji ve Reanimasyon asistanları için nöbet, haftalık masa, rotasyon, işlem karnesi, nöbet değişimi ve izin planı portalı.

- **Site:** GitHub Pages (`index.html` tek dosya)
- **Veri ve giriş:** Google Firebase (Firestore + Authentication)
- **Güvenlik kuralları:** `firestore.rules` — Firebase Console → Firestore → Rules sekmesine yapıştırılır.

Kod güncellemeleri yalnızca sayfayı değiştirir; Firestore'daki verilere dokunmaz.
